# ToolManager 使用手冊

ToolManager 是部門工具的「應用程式商店」：在這裡找工具、一鍵安裝，有新版本時會提醒你更新。

> 寫工具、要上架工具的同仁，請看[作者手冊](AUTHOR_GUIDE.md)。

## 1. 安裝與第一次設定

1. 執行管理員提供的 `ToolManagerSetup-<版本>.exe`。不需要系統管理員權限，程式裝在 `%LOCALAPPDATA%\ToolManager\`。
2. 從開始功能表開啟 **ToolManager**，第一次會出現設定精靈：
   - **伺服器**：通常已由部門預先填好，直接按「下一步」。
   - **存取 Token**：
     1. 按「開啟 Bitbucket」，進入「HTTP access tokens」頁面。找不到時：右上角頭像 → Manage account → HTTP access tokens。
     2. 建立一組 token，名稱可填「ToolManager」，權限選 **Repository read**。可以設定到期日。
     3. 複製 token，貼回 ToolManager，按「驗證並繼續」。
   - Token 存在 Windows 認證管理員，不會寫進任何檔案。
3. 看到「已連線，帳號：…」就完成了。

Token 過期時，到「設定 → 連線」貼上新的 token 即可。

## 2. 找工具

- **所有工具**：左側依分類瀏覽，上方搜尋框可以搜名稱、說明和 README 內容。
- **我的最愛**：點工具卡片或詳情頁的星號就會加入。
- **最近使用**：開啟或執行過的工具會自動出現在這裡。
- 點工具卡片進入**詳情頁**，可以看到說明、擁有者，以及右側的「版本歷史」（每個版本的更新說明）。

## 3. 安裝、開啟、更新

| 工具類型 | 詳情頁的按鈕 | 說明 |
|---|---|---|
| 執行檔 | 安裝 → 開啟 | 解壓即用的程式 |
| Python 腳本 | 安裝 → 執行 | 在執行頁填表單後執行，見第 4 節 |
| 安裝程式 | 下載並開啟安裝程式 | ToolManager 只負責下載，安裝由工具自己的安裝程式完成 |

- **有新版本時**：
  - 詳情頁會出現「更新至 x.y.z」。
  - 「已安裝」頁可以「全部更新」。
  - 系統匣會跳出通知，同一個版本只通知一次。
- **建議盡快更新**：作者標示為重要的更新（例如修正嚴重錯誤）會以琥珀色提示，並附上原因。請儘早更新。
- **自動更新**：詳情頁的「自動更新」開關打開後，該工具有新版時會在背景自動更新。
- **安裝舊版本**：在「版本歷史」中某個版本旁按「安裝此版本」。
- **回到上一版**：新版有問題時，按詳情頁的「⋯」→「切換回 x.y.z」。上一版會保留在電腦上，切換幾乎是立即的。

## 4. 執行 Python 工具

1. 在詳情頁按「執行」，進入執行頁。
2. 填寫表單（標 * 的是必填），按「執行」。
3. 下方會即時顯示輸出，可以按「停止」中斷。
4. 第一次執行，或工具的套件需求有變更時，會先花一點時間「準備 Python 環境」，之後就很快。

- 你不需要自己安裝 Python，ToolManager 已經附帶。
- 有些工具會開啟自己的視窗，或在獨立的命令列視窗中執行（需要你輸入資料時），執行頁會註明。
- 上次填的值會保留，下次開啟執行頁時不用重填。

## 5. 移除與回收區

- **移除工具**：詳情頁「⋯」→「移除」。工具資料夾會移到**回收區**，不會直接刪除。
- **回收區**（上方「回收區」頁）：移除的工具和被取代的舊版本會保留 7 天（可在設定中修改），期間可以「還原」。到期後自動刪除，也可以手動「永久刪除」。
- 如果你在工具資料夾裡建立或修改過檔案（例如設定檔、輸出結果），ToolManager 會提醒你。更新時，這類舊版本會保留下來，不會自動清掉。

## 6. 遇到問題

依序：

1. **先看 README**：詳情頁的說明通常已經回答了「怎麼用」。
2. **查看已知問題**：詳情頁「⋯」→「查看已知問題」，在 Jira 中列出這個工具還沒解決的問題。
3. **回報新問題**：詳情頁「⋯」→「回報新問題」，會開啟已預先填好工具名稱、版本、系統資訊與最近一次執行輸出的 Jira 建單頁，補上「發生了什麼事、你預期的結果」即可送出。

需要附上 log 時：「設定 → 資料夾 → **匯出診斷資訊**」，把產生的 zip 附在回報中。zip 內不含你的 token。

## 7. 系統匣與開機啟動

- **最小化視窗**：ToolManager 會縮到系統匣，繼續在背景檢查更新。點系統匣圖示即可開啟。
- **關閉視窗（X）**：ToolManager 會完全結束。
- 系統匣選單：開啟 ToolManager、檢查更新、結束。
- 「設定 → 啟動」可以打開「登入 Windows 時自動啟動 ToolManager」，啟動後只在系統匣等候，不會跳出視窗。

## 8. ToolManager 自己的更新

ToolManager 會在背景下載自己的新版本，準備好後頂部會出現「重新啟動以更新至 x.y.z」。按下後幾秒內就會以新版本重新開啟；不按的話，下次啟動時才套用。

如果新版本無法正常啟動，ToolManager 會自動改用前一版，並提示「ToolManager x.y.z 無法正常啟動，已暫時改用前一版」。

## 9. 設定一覽

| 區塊 | 內容 |
|---|---|
| 連線 | 伺服器、Project、Repository、分支、token |
| 啟動 | 登入 Windows 時自動啟動 |
| 更新與回收區 | 檢查更新間隔（預設 4 小時）、回收區保留天數（預設 7 天） |
| Python 套件 | PyPI mirror 網址；環境建立工具（uv，或 venv + pip 備案） |
| 關於 ToolManager | 版本、安裝位置、ToolManager 更新內容 |
| 資料夾 | 開啟資料資料夾、開啟 log 資料夾、匯出診斷資訊 |

## 10. 解除安裝

「Windows 設定 → 應用程式」中解除安裝 **ToolManager**。

- 會移除：程式本身、捷徑、開機啟動項目。
- 會保留：已安裝的工具、回收區與設定（`%LOCALAPPDATA%\ToolManager\`），完成時會顯示這個位置。不需要的話可以自行刪除整個資料夾。
